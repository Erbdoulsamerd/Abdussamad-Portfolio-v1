Case study

A system is only real once someone else can run it.

An identity that only works when its designer is in the room is not an identity, it is a decoration. Enlira's system was built so an internal marketing team could extend it on a Monday morning without asking permission.

One mark with two lockups. Seven colours with defined roles. One typeface across every weight. The constraint is the point — there is very little room to get it wrong.

Principles

  1. Butterfly monogram — single continuous line, never filled.
  2. Horizontal lockup for documents, standalone mark for small sizes.
  3. Forest and gold carry the brand; the other five support.
  4. Gilroy throughout, from thin to heavy.
